# babatundeogunlade.com

Official campaign portal for Hon. Babatunde Sunday Ogunlade. Static site hosted on Vercel.

## Files in the repo root

```
index.html          single-page site (all six pages)
404.html            not-found page
robots.txt          crawler rules
sitemap.xml         sitemap
site.webmanifest    browser/PWA metadata
vercel.json         clean URLs + security headers
.gitignore
assets/             favicon.svg, icon-192.png, icon-512.png,
                    icon-512.png, apple-touch-icon.png, og-image.png
4418043.jpg and the 876469f9-...jpg/png photos go in the root next to index.html
```

## Before going live
- Replace `YOUR_FORM_ID` in `index.html` with your Formspree form ID.
- Replace the placeholder social links with real profile URLs.
- Verify all factual claims on the site.
